# Public package scope

This is a reviewed public projection of the completed study, not the internal workspace or its Git history. Numeric measurements, run IDs, task IDs, verdicts and hashes are retained. Local paths, infrastructure identity and internal review content are removed; original evidence hashes are retained where useful and do not imply the corresponding private files are included.

Excluded: planning documents; lifecycle state; all internal notes, session reports, reviews, friction and escalation records; article drafts and publication metadata; task/system prompts and generated prompt payloads; assistant conversations and review prose; social/hero/chart assets; live configuration and credentials; IP addresses, droplet identities, SSH fingerprints and host inventories; absolute workstation paths; execution DBs, source workspaces, dependency trees, native logs and raw evidence archives. Standard bind/loopback endpoint literals in serving code are configuration, not recorded infrastructure identity.

The frozen tasks-v1 harness, task prompts and hidden tests are not public. Publication graphics and article text live exclusively on the site. The 007 directory contains numerical comparison inputs and public technical documentation only.
